# MVP Implementation Plan

## Цель первой итерации

Получить минимальный запускаемый Godot .NET/C# viewer, который читает пример JSON и отображает трассу.

## Итерация 1

1. Создать Godot .NET проект.
2. Создать основную 3D-сцену.
3. Добавить плоскую площадку заданного размера.
4. Реализовать DTO/модели exported Track JSON.
5. Реализовать `TrackLoader`.
6. Загрузить `examples/courses/basic.json`.
7. Создать конусы по мировым координатам.
8. Реализовать простую камеру первого лица:
   - фиксированная высота;
   - WASD;
   - mouse look;
   - Shift multiplier.
9. Запустить проект и проверить отсутствие ошибок.

## Итерация 2

1. Отрисовать markings.
2. Отрисовать trajectory.
3. Выделить преобразование domain X/Y -> Godot X/Z в единый mapper.
4. Добавить обработку ошибок JSON.

## Итерация 3

1. Выбор JSON-файла пользователем.
2. Перезагрузка трассы без перезапуска приложения.
3. Минимальная UI-панель: название трассы, показать/скрыть trajectory.

## Не реализовывать до отдельного решения

- Editor элементов.
- Editor трассы.
- Автоматические connector splines.
- Web export.
- GitHub Pages deployment.
- Панорамное окружение.
- Забор.
- Checkpoint validation / режим экзамена.
- Автодвижение камеры по trajectory.
- Физику.
- Мотоцикл.

## Definition of Done для первой итерации

- Проект компилируется без ошибок.
- Godot запускает сцену.
- Пример трассы загружается из JSON.
- Конусы визуально находятся в ожидаемых позициях.
- Пользователь свободно перемещается камерой.
- Код структурирован и подробно прокомментирован.
