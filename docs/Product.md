# Product

## Проблема

Новичкам на тренировках по мотоджимхане трудно быстро запомнить новую трассу по одной только 2D-схеме. На трассе перспектива меняется, последовательность элементов забывается, райдер останавливается или ошибается и мешает другим участникам.

## Решение

Простой пространственный тренажёр, позволяющий заранее открыть конкретную трассу, увидеть её в 3D и свободно пройти/проехать её виртуальной камерой.

## Что проект НЕ делает

- Не симулирует физику мотоцикла.
- Не моделирует руль, транспорт или райдера.
- Не оценивает технику пилотирования.
- Не требует реалистичной графики.
- Не содержит мультиплеер.
- Не требует backend для MVP.

## Пользовательский сценарий Viewer

1. Пользователь получает файл или ссылку на трассу.
2. Viewer загружает JSON.
3. На площадке появляются конусы, разметка и траектория.
4. Пользователь перемещается камерой на фиксированной высоте.
5. Управление: WASD, мышь для обзора, Shift для ускорения.

## Визуальная среда

Минимум: плоскость площадки и конусы.

Позже:
- сетчатый 3D-забор;
- панорамное окружение/sky dome;
- узнаваемые ориентиры вокруг реальной площадки.

Окружение нужно для ориентации, а не для геометрической или фотореалистичной точности.
