# MotoGymkhanaTrainer

Небольшой 3D-тренажёр для предварительного ознакомления с трассами мотоджимханы.

Цель проекта — помочь райдерам заранее запомнить последовательность упражнений и пространственную конфигурацию трассы до выезда на реальную площадку.

## Основной принцип

Проект не является симулятором мотоцикла. Пользователь перемещается по площадке камерой от первого лица с фиксированной высотой: WASD, мышь, Shift для ускоренного перемещения.

Трасса создаётся в редакторе из переиспользуемых элементов упражнений. Каждый элемент имеет локальную геометрию, конусы, разметку, вход/выход, траекторию и контрольные точки. На конкретной трассе экземпляр элемента можно перемещать, поворачивать и независимо масштабировать по X/Y, не изменяя исходный шаблон.

Редактор автоматически строит соединительные сплайны между выходом предыдущего элемента и входом следующего. Соединения можно корректировать вручную.

Итоговая трасса экспортируется в самодостаточный JSON. Viewer загружает только этот JSON и не зависит от библиотеки исходных элементов.

## MVP

1. Godot 3D viewer на C#/.NET.
2. Простая площадка.
3. Загрузка одного JSON-файла трассы.
4. Отображение конусов.
5. Отображение цветовой разметки.
6. Отображение траектории.
7. Камера от первого лица: WASD + мышь + Shift.
8. Никакой физики мотоцикла, транспорта, AI, аккаунтов, серверной части и сложной графики.

## Реализовано:
- локальный вьювер для отображения трассы, с возможностью перемещения по ней, отображением траектории и блокированием передвижения в запрещённых зонах.
- редактор элементов.
- редактор трасс.
- редактор площадок, с созданием статических зданий, сооружений, неизменяемых конусов и разметки
- Web viewer через GitHub Pages для открытия в любом браузере для просмотра трассы и перемещения по ней
